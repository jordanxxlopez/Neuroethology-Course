Accessibility

This site is built to be usable with a keyboard, a screen reader, browser zoom and high-contrast or dark display settings.

How the site is built

  • Every page has the same navigation, a skip link to the main content and a logical heading structure.
  • Text and links meet WCAG 2.2 AA contrast in both light and dark modes; links are underlined, and the keyboard focus is always visible.
  • Tables have captions and header cells. Wide tables scroll inside their own region on small screens.
  • Pages work without JavaScript. The only script on the site lists upcoming dates on the home page.
  • The syllabus is available as an HTML page, a PDF and a Word document.

Lecture slides

Slides open in Google Drive's viewer, which works with screen readers and zoom, and can be downloaded as PowerPoint files that include the speaker notes. Figures in the slides come from published research articles; each carries its source and citation.

Requesting another format or reporting a problem

If any material is hard to use, e-mail jlopez11@usc.edu with the page or lecture number and the format you need. For approved accommodations, contact the Office of Student Accessibility Services and see the accommodations policy.
